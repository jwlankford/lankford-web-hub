## Description

When adding a new study to Research Papers, tags are now automatically generated based on the **Title**, **Abstract**, and **Key Findings**.

## Implementation Details

- Added NLP keyword extraction logic in `backend/main.py` inside the `add_research_paper` API endpoint.
- Cleans the text by removing HTML tags (generated by rich text editors in the frontend).
- Filters out common English and research-related stop words (e.g., "results", "analysis", "paper").
- Calculates word frequencies and selects the top 5 most relevant terms as tags.
- Capitalizes the new tags and merges them seamlessly with any custom user-provided tags, ensuring no duplicates.
