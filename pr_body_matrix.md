## Description

This PR enhances the Synthesis Matrix page by making the Paper Title clickable. Clicking a title in the matrix now opens the detailed study modal (the `PaperDetailModal`), which displays all the study metadata including:
- Paper Title
- Authors
- Used For
- Methodology
- Abstract
- Key Analytical Findings

This provides a quick way for users to deep-dive into an indexed study directly from the high-level matrix view without having to switch back to the Research Papers tab.
